Contact

Get support for Camunda or send us your feedback via the following channels.

Support

  • Request support via the Enterprise support process.

  • Find support options in the Help Center or Camunda community forum.

Bugs

  • Send us your bug reports via a support ticket (Enterprise customers) or via the Camunda community forum.

  • Review our technical bug trackers at github.com/camunda/camunda/issues or the quality board.

Community

  • Participate in our community via the Camunda community forum, where you can exchange ideas with other Camunda users and Camunda employees.

  • For all other Camunda community programs and resources, visit the Camunda Developer Hub.

Feature requests

  • Submit a feature request in the Product Roadmap Portal.

  • Open an issue for smaller, technical enhancement requests.

Sales/otherContact us with sales inquiries, information about Camunda 8 performance and benchmarking, or any other queries not covered by the other channels.
Security issues

For security-related issues, see security notices for current information on known issues and how to report a vulnerability so we can solve the problem as quickly as possible.

Note: Do not use GitHub for security-related issues.

Locating Camunda 8 credentials

Need assistance locating your Camunda 8 credentials? You can obtain these credentials from Camunda by submitting a Help Request. To do this, take the following steps:

  1. Log in to Jira.
  2. Click Create in the navigation bar at the top of the page. This launches a Create Issue pop-up.
  3. In the Issue Type field, select Help Request.
  4. In the Help Request Type field, click the option that reads I need the credentials for downloading Camunda.
  5. In the Summary and Description fields, I need the credentials for downloading Camunda will populate by default.
  6. (Optional) Add more details, such as the priority level or authorized support contacts.
  7. Click Create at the bottom of the pop-up Create Issue box.

After completing these steps, your request is generated. Find additional details on submitting a self-service help request here.
