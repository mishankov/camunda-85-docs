completeTask

Complete a task with taskId and optional variables. Returns the task.

completeTask(
  taskId: String!
  variables: [VariableInput!]!
): Task!

Arguments

completeTask.taskId ● String! non-null scalar

completeTask.variables ● [VariableInput!]! non-null input

Type

Task object

Describes the User task.
